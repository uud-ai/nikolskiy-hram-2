# Новости прихода

Каждая новость — отдельный файл `.md` в этой папке. Имя файла лучше начинать
с даты: `2026-10-18-osvyashchenie-ikonostasa.md` (латиницей, без пробелов).

```
---
title: Освящение нового иконостаса
date: 2026-10-18
image: /images/news/ikonostas.jpg
---
Первый абзац текста.

Второй абзац — после пустой строки.
```

- `title` — заголовок, `date` — дата в формате ГГГГ-ММ-ДД.
- `image` — необязательно. Фото кладётся в `public/images/news/`,
  а в новости пишется путь `/images/news/имя-файла.jpg`.
- Новость с будущей датой появится на сайте в этот день.
- Чтобы убрать новость — удалите файл.

Этот файл (README.md) на сайт не попадает.
