# Новости прихода через n8n

Два сценария для [n8n](https://n8n.io):

| Файл | Что делает |
|---|---|
| `1-podborka-novostey.json` | Каждое утро в 8:00 (по Чите) читает RSS-ленты, отбирает свежие новости по теме и присылает подборку в Telegram |
| `2-publikaciya-novosti.json` | Получает от вас в Telegram ссылку на статью → модель ИИ пишет пересказ → бот присылает черновик с кнопками «Опубликовать / Отклонить» → после одобрения новость записывается в `public/news.json`, и GitHub Actions пересобирает сайт |

Раздел «Новости» на сайте (`src/components/sections/news.tsx`) читает `public/news.json` при открытии страницы.

## Формат `public/news.json`

```json
{
  "items": [
    {
      "id": "20261011-190947",
      "title": "Заголовок",
      "date": "2026-10-11",
      "text": "Первый абзац.\n\nВторой абзац.",
      "image": "/images/church.jpg",
      "sourceTitle": "Название источника",
      "sourceUrl": "https://..."
    }
  ]
}
```

`image`, `sourceTitle`, `sourceUrl` — необязательные. Абзацы разделяются пустой строкой (`\n\n`). Новости можно добавлять и вручную — правкой файла прямо на GitHub.

## Настройка

1. **Импорт.** В n8n: *Create workflow → ⋯ → Import from File*, по очереди оба файла.
2. **Telegram-бот.** Создайте бота у @BotFather, в n8n добавьте учётные данные *Telegram API* с его токеном и выберите их во всех узлах Telegram. Свой chat ID узнайте у @userinfobot и впишите в узел «Отправить в Telegram» (сценарий 1) и в узел «Настройки» (сценарий 2). Сообщения из других чатов сценарий 2 игнорирует.
3. **Модель ИИ.** В узле «Модель OpenAI» — учётные данные OpenAI. Можно заменить на Google Gemini: удалить узел и подключить к «Пересказу» узел *Google Gemini Chat Model*.
4. **GitHub.** На GitHub: *Settings → Developer settings → Fine-grained tokens → Generate*: доступ только к репозиторию `nikolskiy-hram-2`, право *Contents: Read and write*. В n8n создайте учётные данные *Header Auth*: имя `Authorization`, значение `Bearer <токен>` — и выберите их в узлах «Получить news.json» и «Сохранить в GitHub».
5. **Источники и тема.** В сценарии 1 — узлы «Источники» (список RSS-лент) и «Отбор по теме» (ключевые слова, срок давности).
6. Проверьте каждый сценарий кнопкой *Test workflow*, затем включите переключателем *Active*.

## Важно

- **Ссылки Google Новостей** ведут на страницу-переадресацию, текст статьи по ним не извлекается. Откройте новость в браузере и пришлите боту прямую ссылку на сайт-источник.
- **Ничего не публикуется без вашего «Опубликовать».** Но черновик всё равно читайте внимательно: модель может ошибиться в имени, сане или дате.
- **Фото** с чужих сайтов сценарий не берёт (авторские права). Своё фото можно добавить вручную: положить файл в `public/images/` и указать путь в поле `image`.
- Сценарии собраны по документации n8n, но не прогонялись на живом сервере. Если при импорте какой-то узел покажет предупреждение, откройте его и заново выберите параметры — логика описана в заметке на поле сценария.
